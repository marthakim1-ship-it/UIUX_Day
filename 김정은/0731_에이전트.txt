## 6단계: 분석 방법 정하기

  다음 순서로 홈페이지 레퍼런스를 분석하는 것을 추천해.

  ### 1. 홈페이지별 개별 분석

  각 홈페이지에서 다음 내용을 찾는다.

  - 디자인 특징
  - 화면 구성
  - 사용자 흐름
  - 문구와 콘텐츠
  - 주요 기능
  - 장점과 단점
  - 참고할 부분

  세부 기준은 나중에 작성할 4단계 내용을 적용한다.

  ### 2. 비슷한 내용 묶기

  여러 홈페이지에서 비슷하게 나타나는 요소를 하나의 그룹으로 묶는다.

  예:

  큰 메인 문구 사용
  제품 화면 이미지 사용
  상단에 문의 버튼 배치
  고객 후기 제공
  가격 정보 비공개

  ### 3. 등장 횟수 확인

  각 요소가 몇 개 홈페이지에서 발견됐는지 기록한다.

  상단 문의 버튼: 80개
  고객 후기 제공: 55개
  가격 공개: 20개

  전체 홈페이지 수와 비율도 함께 표시한다.

  ### 4. 패턴 구분

  - 공통 패턴: 전체 홈페이지 중 30% 이상
  - 반복 패턴: 10% 이상 30% 미만
  - 특이 사례: 10% 미만이지만 참고 가치가 있는 사례

  숫자만으로 판단하지 않고, 좋은 아이디어는 적게 사용됐어도 별도로 기록한다.

  ### 5. 공통점과 차이점 찾기

  - 대부분 사용하는 방식
  - 업종에 따라 달라지는 방식
  - 서로 반대되는 방식
  - 특정 홈페이지만 사용하는 방식

  ### 6. 장점과 문제점 분석

  각 패턴에 대해 다음 내용을 작성한다.

  패턴:
  사용한 홈페이지:
  장점:
  단점:
  어울리는 상황:
  주의할 점:

  ### 7. 최종 인사이트 만들기

  분석 결과를 다음 세 종류로 구분한다.

  - 반드시 참고할 공통 방식
  - 상황에 따라 선택할 방식
  - 차별화를 위해 참고할 독특한 방식

  각 인사이트에는 근거가 된 홈페이지와 출처를 연결한다.

  ### 8. 추가 조사 항목 표시

  자료만으로 판단하기 어려운 내용은 추측하지 않고 다음처럼 표시한다.

  추가 조사 필요:
  확인할 내용:
  현재 부족한 근거:

  이 분석 방법을 그대로 사용할지, 수정할 부분이 있는지 알려줘.
