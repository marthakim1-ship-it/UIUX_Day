- 실제 이미지를 넣는 단계가 아니라 각 이미지 영역에 무엇을 보여줄지 짧게 표시하면 돼

3.긴 상품 구간의 화면 리듬이 단조로운 부분
- 기본 팩 3개, 퓨레 10개와 토핑 5개가 모두 카드 묶음으로 이어져 메인페이지 후반이 카테고리 페이지처럼 느껴질 수 있어

- 새로운 장면을 추가하지 말고 현재 네 장면 안에서 우선순위만 정하면 돼

5.작업 상태와 사용자용 메시지가 같은 강도로 보이는 부분

- 복제하지 않을 요소: Daily Harvest의 식물성·냉동식품 주장, 상품 분류, 사진과 문장
- 병합 우선순위: 중간


(레퍼런스를 결과에 적용하는 방법)
이번 레퍼런스는 세 사이트의 화면을 섞어서 새로운 디자인을 만드는 용도가 아니야 시안3에 남아 있는 세 가지 문제를 각각 하나씩 해결하기 위한 기준으로 사용하면 돼

Chobani에서는 제품명과 맛, 크기, 주요 정보와 관련 상품으로 이어지는 정보 순서만 참고하면 돼 이를 YOVIA에 적용할 때는 대표 상품과 퓨레와 토핑의 정보가 같은 순서로 시작하게 만들고 각 상품군에 필요한 추가 설명만 뒤에 붙이면 돼 Chobani의 색이나 패키지와 영양 정보는 YOVIA와 관계가 없으므로 가져오지 않아야 해

기존 웹디자인 시안1에서는 큰 패키지와 원형 그래픽이 함께 만드는 YOVIA의 시각 언어를 가져오면 돼 완성 색상을 그대로 복원하는 것이 아니라 시안3의 회색 와이어프레임 안에서 어느 구간에 큰 원형이 필요하고 어느 구간은 카드 비교가 필요한지 판단하는 기준으로 사용해야 해

Daily Harvest에서는 바쁜 일상 속 식사 선택을 사용자의 하루와 연결하는 문장 방향만 참고하면 돼 YOVIA의 출근 전, 업무 사이, 캠퍼스와 활동 후 장면을 그대로 유지하면서 각 장면에서 왜 한 팩이 필요한지 먼저 설명하고 그다음 관련 구성을 보여주면 돼 Daily Harvest의 상품군과 식물성 식품 주장을 가져오는 것은 현재 브랜드 설정과 맞지 않아

이렇게 사용성은 정보 순서, 심미성은 원형과 제품 중심의 화면 규칙, 무드는 사용자의 하루를 설명하는 방식만 담당하게 해야 해 한 레퍼런스에서 모든 것을 가져오지 않아야 YOVIA의 기존 방향이 유지되고 병합할 때도 무엇을 선택했는지 설명할 수 있어


이 내용을 설명으로 풀어서 보면, 새 결과를 만든 뒤에는 더 완성되어 보인다는 이유만으로 전체를 교체하면 안 돼 먼저 기존 시안3에서 해결된 문제와 새 결과에서 새롭게 해결된 문제를 나눠서 봐야 해

기존 시안3에서는 퓨레와 토핑의 고유한 이름, 역할이 다른 대표 상품 세 개, 팩·퓨레·토핑의 관계, 네 가지 일상 장면과 원형·곡선의 시각 언어가 이미 해결된 내용이야 이 항목은 새 결과가 다르게 제안하더라도 특별한 문제가 없는 한 기존 내용을 유지해야 해

새 결과에서는 22개 항목을 판매 상품과 용량 변형, 구성 옵션과 추천 조합으로 나누는 기준, 세 페이지의 번호와 이름을 맞추는 기준, 대표 상품과 전체 상품의 다른 설명 역할, 상품군이 바뀔 때 화면의 강약을 조절하는 방법을 가져오면 돼 이것들이 이번 4단계에서 보완하려는 핵심이기 때문이야

반대로 새로운 상품과 기능, 확인되지 않은 효능과 가격, 외부 브랜드의 색과 문장을 그대로 가져온 부분은 제외해야 해 현재 문제를 해결하지 않으면서 YOVIA의 기존 방향만 바꿀 수 있기 때문이야 병합은 예쁜 화면을 고르는 과정이 아니라 현재 문제를 실제로 해결한 부분만 근거를 가지고 선택하는 과정이라고 생각하면 돼

(기존 결과와 새 결과의 병합 기준) 기존 시안3에서 유지할 내용
- 첫 화면의 핵심 문장, 제품 패키지와 원형·곡선 그래픽
- 팩·퓨레·토핑 관계 설명
- 네 가지 일상 장면
- 구성 탐색 예시
- 역할이 다른 대표 상품 3종
- 기본 팩, 퓨레, 토핑, 시그니처와 스타터의 전체 상품 구성
- 확정·제안·보류와 미확정 정보 안내
- 회색 와이어프레임과 둥근 형태의 기본 시각 언어

(새 클라이언트 결과에서 가져올 내용)
- 판매 상품, 용량 변형, 구성 옵션과 추천 조합을 나누는 상품 기준
- 001~022의 통합 상품 정보표
- 대표 상품과 전체 상품의 다른 설명 역할
- 상품군별 정보 순서와 구간 전환 기준
- 원형·곡선 시각 언어를 필요한 구간에만 이어주는 규칙
- 구성 예시와 다음 행동의 단계 통일
- 세 페이지의 상품명·번호·상태 일치

(새 결과에서 가져오지 않을 내용)
- 기존 상품 기준과 충돌하는 새 상품·기능·효능·가격
- 확인되지 않은 듀얼 챔버, 시간 단축 수치와 판매·정기배송 정책
- 기존 네 가지 일상 장면을 대체하는 새로운 사용자 설정
- 외부 레퍼런스의 색상·문장·패키지와 상품 분류를 그대로 옮긴 결과
- 현재 강점을 지우고 모든 구간을 같은 새 카드 디자인으로 교체한 결과
- 메인페이지를 카테고리 페이지처럼 상세 정보만 길게 나열한 결과

[실제 구간별 보완 목표]
(첫 화면)
- `바쁜 하루, 한 팩에 담은 세 가지 구성`과 제품 패키지 중심 구조 유지
- 한 팩의 구조가 준비의 번거로움을 줄이려는 브랜드 이유와 연결되게 보강
- 원형 그래픽은 제품과 세 구성의 관계를 기억하게 하는 역할로 사용

(팩·퓨레·토핑 구조)
- 베이스, 과일 풍미와 견과 식감의 차이를 한 번에 이해하게 유지
- 각 요소가 판매 상품인지 구성 옵션인지 상태를 함께 설명
- 첫 화면과 같은 원형·곡선 규칙으로 브랜드 인상 연결

(일상 장면)
- 현재 네 장면 유지
- 대표 장면과 보조 장면의 크기·문장 길이를 달리해 우선순위 형성
- 건강 효능보다 언제 어떤 구성을 살펴보는지에 집중

(구성 탐색 예시)
- 베이스·퓨레·토핑을 순서대로 고르는 현재 구조 유지
- 실제 구매가 아닌 구성 예시라는 상태와 다음 행동을 같은 단계로 통일
- 상품 기준표와 같은 이름을 사용

(대표 상품 3종)
- 120g 모닝 파우치는 기본 제품 구조를 보여주는 역할
- 7AM 갓생 팩은 베이스·퓨레·토핑의 시그니처 조합을 보여주는 역할
- 스타터 팩은 여러 구성을 처음 경험하는 확장 역할
- 세 상품의 이미지 자리, 제목과 설명에서 역할 차이가 먼저 보이게 구성

(전체 상품)
- 최소 15개 이상을 같은 상품 기준으로 확인 가능하게 유지
- 기본 팩, 퓨레, 토핑, 시그니처와 스타터의 관계를 구간 제목에서 설명
- 모든 항목의 이름·상품군·용량·구성·핵심 특징·상태 순서 통일
- 대표 상품의 반복은 전체 상품 체계 안의 위치를 확인하는 용도로 사용

(마지막 제안)
- 제품 구성 비교와 브랜드 이야기 중 현재 메인페이지가 쌓은 흐름에 맞는 행동을 우선 표시
- 앞에서 사용한 원형·곡선과 큰 문장을 다시 사용해 YOVIA의 인상 회수
- 확정되지 않은 판매·정기배송을 최종 행동처럼 확대하지 않음

[진행 순서]
아래 순서는 앞 단계가 정리되어야 다음 판단을 할 수 있도록 배치한 거야 먼저 상품 기준을 정하지 않으면 페이지마다 번호를 맞출 수 없고 페이지 기준이 맞지 않으면 대표 상품과 전체 상품의 관계도 정확히 정리할 수 없어 그다음에야 레퍼런스를 적용해 화면 강약을 조정하고 새 결과에서 필요한 부분을 선택할 수 있어

즉 이번 작업은 디자인을 먼저 꾸미고 내용을 맞추는 순서가 아니라 상품 기준 정리 → 페이지 내용 통일 → 대표와 전체의 역할 구분 → 레퍼런스 원리 적용 → 선택 병합 순서로 진행하면 돼

1.시안3의 001~022를 판매 상품·용량 변형·구성 옵션·추천 조합으로 분류
2.상품명·상품군·용량·구성·핵심 특징·상태·근거를 하나의 기준표로 작성
3.메인·카테고리·브랜드 소개의 상품 이름과 번호를 기준표에 맞게 정리
4.설계 관점과 디자인 관점의 현재 부족점을 기존 분석 파일 아래에 추가
5.보완 클라이언트 요청문으로 새 결과 생성
6.사용성·심미성·무드 레퍼런스의 원리만 선택해 새 결과와 비교
7.기존 시안3에서 유지할 내용, 새 결과에서 가져올 내용과 제외할 내용을 구분
8.현재 시안3을 기준으로 필요한 내용만 병합해 4단계 결과 작성
9.아래 완료 기준으로 확인한 뒤 다시 보여주기

[완료 확인 기준]
- 001~022가 판매 상품·용량 변형·구성 옵션·추천 조합 중 어디에 해당하는지 구분되었는가
- 같은 기준으로 계산한 고유 상품 또는 제안 상품이 최소 15개 이상인가
- 120g·400g·800g이 상품인지 용량 선택인지 명확한가
- 퓨레 10종과 토핑 5종의 이름·구성·상태가 실제 기준에 맞게 정리되었는가
- 메인·카테고리·브랜드 소개의 상품명·번호·분류·상태가 일치하는가
- 대표 3종이 기본 제품, 시그니처 조합과 스타터 경험이라는 다른 역할을 가지는가
- 대표 상품이 전체 상품 영역에도 포함되고 반복 목적이 다른가
- 상품군이 달라도 공통 정보 순서가 유지되는가
- 첫 화면, 팩·퓨레·토핑 구조, 일상 장면, 구성 예시, 대표 상품과 전체 상품의 역할이 중복되지 않는가
- 구성 예시의 설명과 다음 행동이 같은 확정 단계인가
- 원형·곡선·제품 패키지 중심의 YOVIA 시각 언어가 필요한 구간에서 일관되게 이어지는가
- 대표 상품과 일반 상품, 대표 장면과 보조 장면의 시각적 강약이 구분되는가
- 상태 표시가 브랜드 문장과 상품 정보보다 먼저 보이지 않는가
- 사용성·심미성·무드 레퍼런스가 각각 한 가지 현재 문제를 해결하는 데 사용되었는가
- 기존 분석 파일을 수정하거나 삭제하지 않고 아래에 4단계 분석을 추가했는가
- 새 결과 전체를 교체하지 않고 기존 시안3의 강점과 필요한 보완만 선택해 병합했는가

정리하면 이전 단계에서 부족했던 상품 고유성과 대표 상품 선정 기준을 많이 보완했어 이번 4단계에서는 상품을 더 늘리거나 새로운 기능을 추가할 필요는 없어, 먼저 22개 항목이 판매 상품, 용량 변형, 구성 옵션과 추천 조합 중 무엇인지 하나의 기준으로 정리하고 메인·카테고리·브랜드 소개의 상품 데이터를 맞춰줘, 그다음 대표 3종과 전체 상품의 역할, 원형·곡선 시각 언어, 긴 상품 구간의 화면 리듬을 보완한 새 결과에서 필요한 부분만 시안3에 병합해서 다시 보여주면 됨
